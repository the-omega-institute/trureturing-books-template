# 学术预印本 PDF 规范

`academic` 采用 arXiv 常见的单栏研究预印本外观。arXiv 没有统一的视觉模板；下列技术要求来自其官方提交说明，A4、字号、字体和段落参数则是本项目的版式选择，不应称为 arXiv 强制版式或接收认证。

正文、章节顺序、编号、数学源码、图注与 Lean 引用由各输出共享；版式不改写内容。实现为 Pandoc → Typst，入口 `theme/typst/academic.typ`，生成非 TeX 来源的 PDF。

## arXiv 官方技术要求

以 [PDF submission guidelines](https://info.arxiv.org/help/submit_pdf.html) 和 [TeX submission guidelines](https://info.arxiv.org/help/submit_tex.html) 为准：

- 一份 PDF 包含完整正文和全部静态图件。
- 嵌入所有字体，包括标准字体；使用带轮廓的字体，避免位图字体和 Type 3 字体。“轮廓字体”指字体本身的字形轮廓，不是将全文转为不可检索的矢量路径。
- 文本应可机器读取、搜索与复制。中英文、连字、组合符号和数学都要实际抽查，不能只检查页面看起来正确。
- 不嵌入 JavaScript、电影、动画（包括动画 GIF）或 HTML。交互内容在 PDF 中使用静态图和普通链接。
- 实际由 TeX/LaTeX 生成的论文通常须提交 TeX 源码，不能以只有 PDF 的方式绕过源文件要求。本项目以 Markdown → Typst 生成 PDF；发布 PDF 不等于已向 arXiv 投稿或已获接收。

外部平台的投稿大小限制仅在实际投稿时按该平台的最新说明核对，不作为本项目的出版或导出验收条件。

## 本项目的预印本版式

- 默认 A4（210 × 297 mm）、单栏、四边 25.4 mm；`[pdf] academic_paper` 可另设 Typst 开本。`paper` 仍只控制屏幕版和印刷版。
- `academic` 默认省略可选 PDF 结构标签，以控制长篇书稿的文件体积；保留文本、图像、书签和链接，不降低图像分辨率。需要结构标签时可设 `[pdf] academic_tags = true`；arXiv 不强制要求带结构标签的 PDF。
- `academic` 经 pikepdf/QPDF 无损打包对象流；对无解码参数的 Flate 页面内容流，在适合数值绘图指令的 `FILTERED` 策略与 Zopfli 编码之间择小，解码后的指令字节不变。Zopfli 仅做一次迭代、关闭分块搜索，以限制额外耗时；长篇书稿仍会增加压缩时间。仅在文件缩小时采用压缩结果；图片不重采样、不重新编码，字体流、文本、书签、链接及已启用的结构标签保留。
- 正文 11 pt。拉丁文字优先 New Computer Modern，中文用 Noto Serif CJK / Noto Serif SC；数学用 New Computer Modern Math。
- 中文自然字距、左对齐，行间附加间距 0.6 em；英文两端对齐、允许断词，附加间距 0.45 em。段间附加间距与行间附加间距相同，避免段落边界压缩基线，中文常规段落首行缩进 2 em、英文 1.5 em；标题后首段、列表、定理和证明不缩进。
- 首页面依次放居中题名、副题名、作者、日期和摘要；摘要直接采用该语言的 `book.description`，空值时省略。版本、许可、验证说明与所钉提交紧随摘要。目录与正文自然接续，全书从首页起连续使用阿拉伯页码，页码居中放在页脚。
- 章、部随正文流动，不强制从右页开始，不插入对开空白页，不设页眉。长篇专著仍保留目录、书签和真实章节锚点。
- 一级标题 15 pt，二级 12 pt，三级 11 pt。书名和标题不拆英文单词；等号两侧的短表达式保持相连。
- 正文、标题、表格与链接使用纸面文字色。绿色仍只标 Lean 已验证，红色仍只标开放问题；图中保留内容所需的语义颜色。

## 定理、公式与图表

- 定理标题以粗体标明种类和编号，描述性标题为常规字重。英文定理陈述用斜体，中文用正体；定义、例子和评注用正体。证明独立排段并保留证毕方框，Lean 标记、永久链接与完整验证账本保留。
- 普通行内公式按正文流动，不按“超过半行”强制换行。实际可用宽度会预留一个字宽给尾标点；只有超出该宽度的公式才在式前换行并等比缩小；段落、列表和窄表都按自身宽度计算。显示公式同样适宽，内部换行由原数学源码决定。
- 三线表无彩色底纹与竖线，表内文字 9.5 pt。长标识符在分隔符后换行，窄单元格中的公式不侵入邻列。
- 静态图使用浅色配色，PDF 图内使用 Libertinus Serif、数学字体与 CJK 回退，排除会把符号画成问号方框的 LastResort 占位字体，保留真正的系统及项目字体；标签字符保持原值。图注 10 pt，不加界面装饰。已有图号、锚点与数学编号保持原有规则。
- 代码 0.9 em，Lean 声明名 7.5 pt，脚注 8 pt。长声明名可在点、斜线和下划线后换行，链接目标不变。

## 验收

运行 `./tbook check` 和 `./tbook build pdf --variant academic`；改动工具时运行工具单元测试，纯版式任务核对章节与锁文件没有改动。普通导出先用构建日志与自动检查验收，不默认渲染或逐页查看。仅在出现相关错误或警告，或任务明确要求视觉／版式检查与修复时，按 [book-export](../skills/book-export/SKILL.md) 查看问题涉及的语言、变体与页面；修复已知版面问题时，不以编译成功代替问题处的视觉核对。

用 PDF 检查工具核对所有字体已嵌入、没有 Type 3 字体或嵌入的活动内容，检查文本检索与提取结果。核对书签、交叉引用、页码与链接目标，扫描页面边界。可使用 `pdffonts`、`pdftotext` 或独立 PDF 解析器；这些检查工具不是构建依赖。字体检查提示异常或任务涉及图内组合字符缺字时，再查看对应图件与页面。
