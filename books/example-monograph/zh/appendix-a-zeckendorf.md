# 附录 A 齐肯多夫表示与进位

本附录给出[第一章](ch01-golden-deficit.md)所用的背景。[第一节](#sec-zeckendorf)把齐肯多夫（Zeckendorf）表示写成数字串，陈述它的存在、唯一与保序；[第二节](#sec-carries)给出把两个表示的逐位和化回规范形的四条进位规则。第一章的亏量 $c(v_1, v_2)$（[@def-deficit]）正是这些进位中最低两条规则的带符号计数（[@thm-deficit-integer]）。

Fibonacci 数沿用 Lean（mathlib 的 `Nat.fib`）的约定：$F_0 = 0$，$F_1 = 1$，$F_{n+2} = F_{n+1} + F_n$。

## 数字串与齐肯多夫定理 {#sec-zeckendorf}

第一章把齐肯多夫表示写成 $F_{k_1} + \dots + F_{k_r}$，下标 $k_j \ge 2$。本附录改用从 $0$ 起算的位置：位置 $i$ 对应下标 $k = i + 2$，它的权是

$$
W_i = F_{i+2}, \qquad (W_0, W_1, W_2, W_3, W_4, \dots) = (1, 2, 3, 5, 8, \dots).
$$

这样，进位可以写成数字串上的局部改写，并且允许某一位暂时大于 $1$。

::: {.definition #def-canonical-raw title="规范数字串与它的值" lean="D5/S1/Digit/Raw.CanonicalRaw D5/S1/Digit/Raw.rawValue"}
数字串是只在有限个位置上非零的函数 $r : \mathbb{N} \to \mathbb{N}$，$r(i)$ 是位置 $i$ 上的数字，可以大于 $1$。它的值是

$$
\mathrm{val}(r) = \sum_{i} r(i)\, W_i .
$$

数字串 $r$ 称为规范的，如果每个数字至多为 $1$，并且没有两个相邻的 $1$：对所有 $i$，$r(i) \le 1$，且 $r(i) = 1$ 时 $r(i+1) = 0$。
:::

Lean 中数字串的类型是 `RawDigits`（即 `ℕ →₀ ℕ`），值与规范性分别是 [`rawValue`](lean:D5/S1/Digit/Raw.rawValue) 与 [`CanonicalRaw`](lean:D5/S1/Digit/Raw.CanonicalRaw)。书写数字串时从高位写到低位，并加下标 $W$：$10101_W$ 在位置 $4$、$2$、$0$ 上各有一个 $1$，值为 $8 + 3 + 1 = 12$；$202_W$ 在位置 $2$ 与 $0$ 上各有一个 $2$，值为 $2 \cdot 3 + 2 \cdot 1 = 8$，不是规范的。数字串可以逐位相加。记 $e_i$ 为只在位置 $i$ 上为 $1$ 的数字串，例如 $202_W = 2e_2 + 2e_0$。

对自然数 $n$，记 $\mathrm{zeck}(n)$ 为 $n$ 的齐肯多夫下标列表（Lean 中的 `Z n`，其中的列表就是 mathlib 的 `Nat.zeckendorf n`）。按构造，它从大到小列出若干 Fibonacci 下标，每个下标至少为 $2$，相邻两项之差至少为 $2$。把每个下标减 $2$，得到数字串 $z(n)$（Lean 中的 `toRaw (Z n)`）。例如 $\mathrm{zeck}(12) = [6, 4, 2]$，$z(12) = 10101_W$。

::: {.theorem #thm-zeckendorf-exists title="齐肯多夫表示存在" lean="D5/S1/Digit/Addition.rawValue_toRaw_Z"}
对每个自然数 $n$，

$$
\mathrm{val}(z(n)) = n,
$$

其中 $z(n)$ 是把 $n$ 的齐肯多夫下标列表 $\mathrm{zeck}(n)$ 的每个下标减 $2$ 得到的数字串。
:::

::: proof
把下标减 $2$ 再按 $W_i = F_{i+2}$ 求值，等于直接对列表中的下标 $k$ 求 $F_k$ 之和；后者等于 $n$，这是 mathlib 的 `Nat.sum_zeckendorf_fib`。完整证明由 Lean 内核检查。
:::

$\mathrm{zeck}(n)$ 按构造满足齐肯多夫条件，[@thm-zeckendorf-exists] 说它的和确实是 $n$，所以每个自然数都有齐肯多夫表示。数字串 $z(n)$ 也是规范的，这是 trureturing 同一模块中的 `canonicalRaw_toRaw`，本书没有单独引用它。定理只断言值，不涉及怎样求出 $\mathrm{zeck}(n)$。

::: {.theorem #thm-zeckendorf-unique title="齐肯多夫表示唯一" lean="D5/S1/Digit/Normalize.canonicalRaw_unique"}
设 $r$、$s$ 是两个规范数字串。若 $\mathrm{val}(r) = \mathrm{val}(s)$，则 $r = s$。
:::

::: proof
Lean 证明把问题交给 mathlib。把规范数字串 $r$ 的位置各加 $2$、从大到小排列，得到一个齐肯多夫下标列表；由 mathlib 的唯一性定理 `Nat.zeckendorf_sum_fib`，它就是 $\mathrm{zeck}(\mathrm{val}(r))$。$r$ 与 $s$ 的值相同，所以得到同一个列表；从列表出发把下标减 $2$ 又能还原数字串，于是 $r = s$。完整证明由 Lean 内核检查。
:::

规范性不能去掉：$2e_1 = 20_W$ 与 $e_2 + e_0 = 101_W$ 的值都是 $4$，只有后者是规范的。合起来，每个自然数 $n$ 恰有一个规范数字串，就是 $z(n)$；这就是齐肯多夫定理[^zeck]。下表列出 $1$ 到 $20$ 的表示，最后一列右对齐。

| $n$ | 齐肯多夫表示 | $\mathrm{zeck}(n)$ | $z(n)$ |
| ---: | :--- | :--- | ---: |
| 1 | $1$ | $[2]$ | 1 |
| 2 | $2$ | $[3]$ | 10 |
| 3 | $3$ | $[4]$ | 100 |
| 4 | $3 + 1$ | $[4, 2]$ | 101 |
| 5 | $5$ | $[5]$ | 1000 |
| 6 | $5 + 1$ | $[5, 2]$ | 1001 |
| 7 | $5 + 2$ | $[5, 3]$ | 1010 |
| 8 | $8$ | $[6]$ | 10000 |
| 9 | $8 + 1$ | $[6, 2]$ | 10001 |
| 10 | $8 + 2$ | $[6, 3]$ | 10010 |
| 11 | $8 + 3$ | $[6, 4]$ | 10100 |
| 12 | $8 + 3 + 1$ | $[6, 4, 2]$ | 10101 |
| 13 | $13$ | $[7]$ | 100000 |
| 14 | $13 + 1$ | $[7, 2]$ | 100001 |
| 15 | $13 + 2$ | $[7, 3]$ | 100010 |
| 16 | $13 + 3$ | $[7, 4]$ | 100100 |
| 17 | $13 + 3 + 1$ | $[7, 4, 2]$ | 100101 |
| 18 | $13 + 5$ | $[7, 5]$ | 101000 |
| 19 | $13 + 5 + 1$ | $[7, 5, 2]$ | 101001 |
| 20 | $13 + 5 + 2$ | $[7, 5, 3]$ | 101010 |

表中每一行都由程序算出，并核对了规范性与 $\mathrm{val}(z(n)) = n$。程序还列出了位置都小于 $14$ 的全部规范数字串：共 $987$ 个（含全为 $0$ 的串），值恰好是 $0$ 到 $986$，各出现一次。这些是有限的计算，不是证明；一般情形由 [@thm-zeckendorf-exists] 与 [@thm-zeckendorf-unique] 保证。

右对齐之后，$z(n)$ 一列从上到下像计数一样递增：比较两个数字串，只需从最高位起找第一处不同。下面的命题用下标列表说的就是这件事。

::: {.proposition #prop-zeckendorf-order title="字典序就是大小" lean="D5/S1/Words/ZeckendorfOrder.zeckendorf_lex_iff_lt"}
对所有自然数 $m$、$n$，

$$
\mathrm{zeck}(m) <_{\mathrm{lex}} \mathrm{zeck}(n) \iff m < n .
$$

这里 $<_{\mathrm{lex}}$ 是列表的严格字典序：从第一项起逐项比较，在第一处不同的位置上该项较小的列表较小；若一个列表是另一个的真前缀，则较短的较小。
:::

例如 $\mathrm{zeck}(5) = [5]$ 是 $\mathrm{zeck}(6) = [5, 2]$ 的真前缀，$[5, 2] <_{\mathrm{lex}} [5, 3] = \mathrm{zeck}(7)$，$[5, 3] <_{\mathrm{lex}} [6] = \mathrm{zeck}(8)$，与 $5 < 6 < 7 < 8$ 一致。列表从最大的下标开始，所以字典序就是从最高位起比较数字串，与比较十进制数的方法相同；这是本书对命题的改述，Lean 陈述针对的是下标列表。命题只涉及齐肯多夫列表：$[4, 3]$ 与 $[5]$ 都表示 $F_4 + F_3 = F_5 = 5$，前者按字典序却更小。

[^zeck]: 以 Édouard Zeckendorf 命名，他在 1972 年发表了这一结果；C. G. Lekkerkerker 在 1952 年已经发表过。

## 进位 {#sec-carries}

两个规范数字串逐位相加，得到的数字串可能某一位是 $2$，也可能出现相邻的 $1$。进位规则把它们局部地改写掉。Lean 中共有四条规则（`CarryStep` 的四个构造子），每条只改动两三个位置，其余部分 $q$ 原样保留。$q$ 可以是任意数字串，所以规则只要求被改写的位置上有足够的数字：例如位置 $i$ 上是 $2$、位置 $i+1$ 上是 $1$ 时，相邻进位只用掉位置 $i$ 上的一个 $1$。

相邻进位 `adjacent`
: $q + e_i + e_{i+1} \to q + e_{i+2}$，对每个 $i$。

最低重复进位 `double_zero`
: $q + 2e_0 \to q + e_1$。

次低重复进位 `double_one`
: $q + 2e_1 \to q + e_0 + e_2$。

一般重复进位 `double_succ`
: $q + 2e_{i+2} \to q + e_i + e_{i+3}$，对每个 $i$。

::: {.figure src="carry-rules"}
**四条进位规则。** 每行左边是改写前的数字，右边是改写后的数字；青色一行的电荷为 $+1$，品红一行的电荷为 $-1$。
:::

图中每行上方是规则名与它所依据的恒等式，方框上方是位置，数字从高位写到低位，没有画出的位置保持不变。中间两行是两条最低的重复进位，右侧的 $+1$ 与 $-1$ 是第一章带符号计数中给它们的记号，下文称为电荷（见 [@thm-charge-unique]）；另外两条规则的电荷为 $0$。

::: {.lemma #lem-carry-value title="进位不改变值" lean="D5/S1/Digit/Carry.rawValue_carryStep"}
若数字串 $r$ 经一步进位变为 $s$，则 $\mathrm{val}(r) = \mathrm{val}(s)$。
:::

::: proof
求值对逐位加法可加，未改动的部分 $q$ 在两边相同，所以只需看被改写的部分。四条规则依次对应恒等式 $W_i + W_{i+1} = W_{i+2}$、$2W_0 = W_1$（即 $2 = 2$）、$2W_1 = W_0 + W_2$（即 $4 = 1 + 3$）与 $2W_{i+2} = W_i + W_{i+3}$。第一个就是递推式，最后一个用两次递推式：$2W_{i+2} = W_{i+2} + W_{i+1} + W_i = W_{i+3} + W_i$。完整证明由 Lean 内核检查。
:::

最低两条规则单独列出，是因为一般规则在最低两位借不到更低的位置。用 Fibonacci 数写，一般规则是 $2F_k = F_{k-2} + F_{k+1}$。在 $k = 2$ 时右边的 $F_0 = 0$ 消失，得到 $2W_0 = W_1$；在 $k = 3$ 时右边是 $F_1 + F_4$，而 $F_1 = 1 = F_2$ 只能写在位置 $0$ 上，得到 $2W_1 = W_0 + W_2$。这两处变通正是第一章亏量的来源，见 [@lem-face-invariant] 之后的说明。

::: {.theorem #thm-carry-confluent title="进位合流" lean="D5/S1/Digit/CarryStepConfluence.carryStep_confluent"}
记 $r \to^* s$ 表示数字串 $r$ 经有限步（可以是零步）进位变为 $s$。对所有数字串 $r$、$s$、$t$：若 $r \to^* s$ 且 $r \to^* t$，则存在数字串 $u$，使得 $s \to^* u$ 且 $t \to^* u$。
:::

::: proof
Lean 证明不逐一检查规则重叠的情形，而是借助下文的规范化过程 $\mathrm{normalize}$。它有三条性质：每一步进位都使全部数字之和减少，或者数字之和不变而位置的某个加权和减少，所以规范化必然停止；停止时数字串是规范的；由 [@lem-carry-value]，它不改变值。于是沿任何进位路径，两端规范化的结果都是规范的、值相同，由 [@thm-zeckendorf-unique] 相等。取 $u = \mathrm{normalize}(r)$：从 $s$ 与 $t$ 出发各自规范化，都到达 $u$。完整证明由 Lean 内核检查。
:::

合流说的是终点，不是步数，也不包括终止性。进位不能无限进行下去，是 trureturing 中另一条定理 `carryStep_measure_decreases` 的推论，本书没有单独引用。

规范化过程 $\mathrm{normalize}$（Lean 中的 `normalize`）每一步只做一次进位：

1. 若有数字不小于 $2$ 的位置，取其中最低的位置，作用相应的重复进位（位置 $0$、位置 $1$ 与更高的位置各有一条规则）；
2. 否则，若有相邻的两个 $1$，取最低的一对，作用相邻进位；
3. 否则数字串已经规范，停止。

::: {.theorem #thm-zeck-add title="黄金加法" lean="D5/S1/Digit/Addition.zeck_add"}
对所有自然数 $m$、$n$，

$$
z(m + n) = \mathrm{normalize}\bigl(z(m) + z(n)\bigr),
$$

其中数字串的加法是逐位相加。
:::

也就是说，把两个规范数字串逐位相加，再按上面的过程一步步进位，得到的正是和的规范数字串。以 $4 + 7$ 为例：$z(4) = 101_W$，$z(7) = 1010_W$，逐位相加得 $1111_W$。规范化过程依次作用四次进位：

| 步 | 作用的进位 | 数字串 | 值 |
| ---: | :--- | ---: | :--- |
| 0 | （逐位相加） | 1111 | $5 + 3 + 2 + 1 = 11$ |
| 1 | 相邻进位，位置 $0, 1 \to 2$ | 1200 | $5 + 2 \cdot 3 = 11$ |
| 2 | 一般重复进位，位置 $2 \to 0, 3$ | 2001 | $2 \cdot 5 + 1 = 11$ |
| 3 | 一般重复进位，位置 $3 \to 1, 4$ | 10011 | $8 + 2 + 1 = 11$ |
| 4 | 相邻进位，位置 $0, 1 \to 2$ | 10100 | $8 + 3 = 11$ |

第 1 步之后位置 $2$ 上是 $2$。规范化过程先处理重复的数字，所以第 2 步用一般重复进位，尽管位置 $2$、$3$ 也可以作用相邻进位。结果 $10100_W = z(11)$，与 [@thm-zeck-add] 一致。四步都是内部进位，没有用到最低两条规则，所以 $c(4, 7) = 0$，与第一章 [@ex-small-deficits] 的表相符。

步数并不唯一。同样从 $1111_W$ 出发，先在位置 $0, 1$ 作用相邻进位得 $1200_W$，再在位置 $2, 3$ 作用相邻进位（位置 $2$ 上的 $2$ 只用掉一个 $1$），两步就到 $10100_W$。程序穷举表明，从 $1111_W$ 出发共有 $4$ 条进位路径，长度分别为 $2, 2, 3, 4$，终点都是 $10100_W$。[@thm-zeck-add] 只说规范化过程的结果，不给进位次数的界。

第一章的 $\beta$ 把位置 $i$ 上的数字放在 $\varphi^{i+2}$ 上（第一章写作 $F_k \mapsto \varphi^k$，$k = i + 2$），收缩面读数 $\beta'$ 则放在 $\psi^{i+2}$ 上。对任意数字串 $r$ 与 $x \in \{\varphi, \psi\}$，记

$$
\langle r \rangle_x = \sum_i r(i)\, x^{i+2},
$$

于是 $\beta(v) = \langle z(v) \rangle_\varphi$，$\beta'(v) = \langle z(v) \rangle_\psi$。进位改变数字串时，这两个读数怎样变化？

::: {.lemma #lem-face-invariant title="内部进位在 $\varphi$、$\psi$ 两面上都不花钱" lean="D5/S1/Deficit/GoldenCarryLedger.carry_rewrite_face_invariant"}
设 $\varphi = (1+\sqrt5)/2$，$\psi = (1-\sqrt5)/2$。对每个自然数 $k$，$x = \varphi$ 与 $x = \psi$ 都满足

$$
x^{k+1} + x^{k+2} = x^{k+3}, \qquad 2x^{k+2} = x^{k+3} + x^{k} .
$$
:::

::: proof
两个恒等式只用到 $x^2 = x + 1$，而 $\varphi$、$\psi$ 正是这个方程的两个根。第一个恒等式是 $x^2 = x + 1$ 乘以 $x^{k+1}$。对第二个，由 $x^3 = x \cdot x^2 = x^2 + x = 2x + 1$ 得 $x^3 + 1 = 2x + 2 = 2x^2$，再乘以 $x^k$。完整证明由 Lean 内核检查。
:::

把四条进位规则代入 $\langle \cdot \rangle_x$：

- 相邻进位 $e_i + e_{i+1} \to e_{i+2}$ 把 $x^{i+2} + x^{i+3}$ 换成 $x^{i+4}$。由第一个恒等式（$k = i + 1$），读数不变。
- 一般重复进位 $2e_{i+2} \to e_i + e_{i+3}$ 把 $2x^{i+4}$ 换成 $x^{i+2} + x^{i+5}$。由第二个恒等式（$k = i + 2$），读数不变。
- 最低重复进位 $2e_0 \to e_1$ 把 $2x^2$ 换成 $x^3$。第二个恒等式在 $k = 0$ 时是 $2x^2 = x^3 + 1$，所以读数恰好减少 $1$。
- 次低重复进位 $2e_1 \to e_0 + e_2$ 把 $2x^3$ 换成 $x^2 + x^4$。第二个恒等式在 $k = 1$ 时是 $2x^3 = x^4 + x$，所以读数的减少量是 $x - x^2 = -1$，即增加 $1$。

所以内部进位在两个面上都不改变读数；只有最低两条规则改变读数，而且在两个面上改变同一个整数。这一对应是本书的说明，[@lem-face-invariant] 本身只陈述幂恒等式。$k = 0$ 与 $k = 1$ 的恒等式里出现 $x^0$ 与 $x^1$，没有数字串的位置对应它们，这就是上面所说的变通。

由 [@thm-zeck-add] 与 $\langle \cdot \rangle_\varphi$ 对逐位加法的可加性，

$$
c(v_1, v_2) = \bigl\langle z(v_1) + z(v_2) \bigr\rangle_\varphi - \bigl\langle \mathrm{normalize}\bigl(z(v_1) + z(v_2)\bigr) \bigr\rangle_\varphi ,
$$

即规范化过程中 $\varphi$ 面读数的总减少量：最低重复进位的次数减去次低重复进位的次数。这正是 [@thm-deficit-integer] 的第三部分。$\psi$ 面的总减少量与此相同，对应它的第一部分。

第一章把最低两条重复进位分别记为 $+1$ 与 $-1$。一般地，给每一步进位记一个电荷：最低重复进位记 $+1$，次低重复进位记 $-1$，另外两条规则记 $0$。一条有限进位路径的电荷是各步电荷之和，零步的路径电荷为 $0$。写 $r \Rightarrow_z s$，表示有一条从 $r$ 到 $s$、电荷为 $z$ 的进位路径。

::: {.theorem #thm-charge-unique title="进位电荷与路径无关" lean="D5/S1/Deficit/ChargedCarryPath.charged_normal_form_unique"}
对所有数字串 $r$、$s$、$t$ 与整数 $z$、$w$：若 $r \Rightarrow_z s$，$r \Rightarrow_w t$，并且 $s$、$t$ 都是规范的，则 $s = t$ 且 $z = w$。
:::

::: proof
终点：两条路径去掉电荷后都是普通的进位路径，终点规范；按 [@thm-carry-confluent] 证明中的论证，它们都等于 $\mathrm{normalize}(r)$。电荷：Lean 在 $\mathbb{Z}[\varphi]$ 中记账，每一步带电荷的进位使 $\langle \cdot \rangle_\varphi$ 恰好减少它的电荷，这就是 [@lem-face-invariant] 之后的计算。所以一条路径的电荷等于起点与终点读数之差，只取决于两端。终点相同，电荷也就相同。完整证明由 Lean 内核检查。
:::

以 $6 + 6$ 为例：$z(6) = 1001_W$，逐位相加得 $2002_W$。程序穷举表明，从它出发共有三条进位路径，都走到 $10101_W = z(12)$：

| 路径 | 经过的数字串 | 各步电荷 | 总电荷 |
| :--- | :--- | :--- | ---: |
| 一（规范化过程） | 2002 → 2010 → 10020 → 10101 | $+1, 0, -1$ | $0$ |
| 二 | 2002 → 10012 → 10101 | $0, 0$ | $0$ |
| 三 | 2002 → 10012 → 10020 → 10101 | $0, +1, -1$ | $0$ |

第二条路径完全不用最低两条规则：它的最后一步是位置 $0, 1$ 上的相邻进位，位置 $0$ 上的 $2$ 只用掉一个 $1$。另两条路径各用一次 $+1$ 与一次 $-1$。三者的总电荷都是 $0 = c(6, 6)$。

把 [@thm-charge-unique] 与 [@thm-deficit-integer] 的第三部分合起来：从 $z(v_1) + z(v_2)$ 出发、走到规范数字串的任何一条进位路径，终点都是 $z(v_1 + v_2)$，总电荷都是 $c(v_1, v_2)$。这一步还要用到 trureturing 中的 `charged_normalize_exists`（规范化过程本身是一条带电荷的路径，电荷就是它的带符号计数），本书没有单独引用这条声明。所以亏量是黄金加法本身的不变量，与进位的顺序无关。对 $v_1, v_2 < 30$ 的全部 $900$ 对，程序穷举了全部 $4431$ 条进位路径，终点与总电荷都与此相符；这是有限的计算，不是证明。

[@thm-charge-unique] 对任意数字串成立，但不限制电荷的大小。[@thm-deficit-three-valued] 保证总电荷落在 $\{-1, 0, 1\}$ 中，但只针对两个规范数字串之和。例如从 $5e_0$（位置 $0$ 上为 $5$，值为 $5$）出发，规范化过程走 $5$ 步到 $1000_W = z(5)$，总电荷为 $2$；直接计算也是 $5\varphi^2 - \varphi^5 = 2$。
