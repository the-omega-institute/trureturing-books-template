理论接口 · 这个页面在演示什么Theory interface · what this page shows

每个自然数 v 都唯一地写成互不相邻的 Fibonacci 数之和（Zeckendorf 表示 Z(v)），权重 W₀ = F₂ = 1、W₁ = F₃ = 2、W₂ = 3、W₃ = 5……。把权重 Wᵢ 换成 φ^(i+2) 得到 β(v)。β 不保持加法，差额就是亏量 c(v₁, v₂) = β(v₁) + β(v₂) − β(v₁ + v₂)。本页是数值演示，不是证明。

  1. 进位。舞台上每一格是一个权重，格里的筹码数就是这一位的数字。Z(v₁) 与 Z(v₂) 逐位相加后可能出现两枚筹码挤在一格，或相邻两格各有一枚。每一步触发一条规则：优先在最低的“两枚”处做重复进位（R₀：2·W₀ → W₁；R₁：2·W₁ → W₀ + W₂；Rⱼ：2·Wⱼ → Wⱼ₋₂ + Wⱼ₊₁），没有“两枚”时在最低的相邻一对处做相邻进位 A：Wⱼ + Wⱼ₊₁ → Wⱼ₊₂，直到得到 Z(v₁ + v₂)。这与 trureturing 中 carryPass 的顺序相同。Rⱼ（j ≥ 2）与 A 不改变 β；R₀ 使 β 减少 1，R₁ 使 β 增加 1。舞台上方的标尺画出当前数字串的 β 比终点多出几格；它只在这两条规则处移动，所以 c 等于 R₀ 的次数减去 R₁ 的次数。
  2. 精确计算。β(v) 写成 a + bφ，整数 a、b 由 φ^k = F(k−1) + F(k)·φ 得到（只用 φ² = φ + 1），所以 b 恰好是 v 本身。亏量的 φ 系数因此是 v₁ + v₂ − (v₁ + v₂) = 0：c 是一个整数，页面不做浮点近似。
  3. 亏量图。逐格画出 0 ≤ v₁, v₂ ≤ N 上的 c；琥珀色十字标出当前一对。图关于对角线对称（c 的定义对 v₁、v₂ 对称）；把范围拉远到 0 … 987，近一百万格里仍然只有三种颜色。网格只是有限的检查，结论的一般性来自 Lean 定理。
  4. 相位正方形。记 p(v) = {(v + 1)φ}。一对数是单位正方形里的点 (p(v₁), p(v₂))，两条斜线 p₁ + p₂ = 1/φ 与 p₁ + p₂ = φ 把正方形分成 c = +1、0、−1 三块。两块三角形的面积是 1/(2φ²) ≈ 0.1910 与 1/(2φ⁴) ≈ 0.0729。
  5. 窗口。在收缩面上把 φ 换成 ψ = 1 − φ，得到 β′(v)。每个 β′(v) 落在长度为 1 的窗口 [−1/φ², 1/φ] 内，而 c = β′(v₁) + β′(v₂) − β′(v₁ + v₂)，所以 c 介于 φ − 3 ≈ −1.382 与 φ ≈ 1.618 之间；它又是整数，只能是 −1、0、1。

Every natural number v is, in exactly one way, a sum of nonadjacent Fibonacci numbers (its Zeckendorf representation Z(v)), with weights W₀ = F₂ = 1, W₁ = F₃ = 2, W₂ = 3, W₃ = 5, …. Replacing each weight Wᵢ by φ^(i+2) gives β(v). β does not preserve addition, and the difference is the deficit c(v₁, v₂) = β(v₁) + β(v₂) − β(v₁ + v₂). The page is a numerical illustration, not a proof.

  1. The carries. On the stage each cell is a weight and the number of tokens in it is that digit. Adding Z(v₁) and Z(v₂) digit by digit can leave two tokens in one cell, or one token in each of two neighbouring cells. Each pass fires one rule: a repeated carry at the lowest pair of tokens (R₀: 2·W₀ → W₁; R₁: 2·W₁ → W₀ + W₂; Rⱼ: 2·Wⱼ → Wⱼ₋₂ + Wⱼ₊₁) if there is one, otherwise the adjacent carry A: Wⱼ + Wⱼ₊₁ → Wⱼ₊₂ at the lowest adjacent pair, until Z(v₁ + v₂) is reached. This is the order of carryPass in trureturing. Rⱼ (j ≥ 2) and A leave β unchanged; R₀ lowers β by 1 and R₁ raises it by 1. The gauge above the tokens shows by how many units β of the current string exceeds β of the result; it moves only at those two rules, so c is the number of R₀ carries minus the number of R₁ carries.
  2. Exact arithmetic. β(v) is written as a + bφ with integers a, b, using φ^k = F(k−1) + F(k)·φ (nothing but φ² = φ + 1), so b is v itself. The φ-coefficient of the deficit is therefore v₁ + v₂ − (v₁ + v₂) = 0: c is an integer, and the page never rounds it.
  3. The deficit map. It draws c cell by cell for 0 ≤ v₁, v₂ ≤ N; the amber cross marks the current pair. The map is symmetric about the diagonal (the definition of c is symmetric in v₁ and v₂); zoomed out to 0 … 987, almost a million cells still show three colours only. The grid is a finite check; the general statement comes from the Lean theorems.
  4. The phase square. Let p(v) = {(v + 1)φ}. A pair is the point (p(v₁), p(v₂)) of the unit square, and the lines p₁ + p₂ = 1/φ and p₁ + p₂ = φ cut the square into the regions c = +1, 0 and −1. The two triangles have areas 1/(2φ²) ≈ 0.1910 and 1/(2φ⁴) ≈ 0.0729.
  5. The window. On the contraction face φ is replaced by ψ = 1 − φ, which gives β′(v). Every β′(v) lies in the window [−1/φ², 1/φ] of length 1, and c = β′(v₁) + β′(v₂) − β′(v₁ + v₂), so c lies between φ − 3 ≈ −1.382 and φ ≈ 1.618; being an integer, it is −1, 0 or 1.
