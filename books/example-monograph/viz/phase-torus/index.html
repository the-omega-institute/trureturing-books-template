LEAN ✓相位判据。记 p(v) = {(v + 1)φ}，B = s(v₁) + s(v₂) − s(v₁ + v₂)，s(v) = ⌊(v + 1)φ⌋ − 1：B = 1 当且仅当 p(v₁) + p(v₂) < 1/φ；B = −1 当且仅当 p(v₁) + p(v₂) ≥ φ；其余情形 B = 0。环面的颜色就是这三块。已冻结：The phase criterion. With p(v) = {(v + 1)φ}, B = s(v₁) + s(v₂) − s(v₁ + v₂) and s(v) = ⌊(v + 1)φ⌋ − 1: B = 1 iff p(v₁) + p(v₂) < 1/φ; B = −1 iff p(v₁) + p(v₂) ≥ φ; otherwise B = 0. These three regions are the colours of the torus. Frozen: golden_phase_deficit

理论接口 · 这个页面在演示什么Theory interface · what this page shows

相位 p(v) = {(v + 1)φ} 只看小数部分，取值在 [0, 1) 里，0 与 1 是同一个相位。所以相位正方形的左边与右边是同一条线，上边与下边也是；把它们粘起来，正方形成了环面。本页是数值演示，不是证明。

  1. 依据的章节。第一章 · 相位判据：亏量 c = B 由两个相位之和决定（golden_phase_deficit，LEAN ✓）。
  2. 两条斜线是一条。因为 φ = 1 + 1/φ，p₁ + p₂ = φ 就是 p₁ + p₂ ≡ 1/φ（mod 1），和 p₁ + p₂ = 1/φ 是环面上同一条闭曲线的两段。页面把它画成一条紫色的管子，并核对两段在粘合处首尾相接（NUM）。
  3. 示意与简化。管子与环面的粗细、比例是画面的选择（MODEL）；珠子是 0 ≤ v₁, v₂ ≤ 7 的 64 对相位，按页面算出的 c 着色。

A phase p(v) = {(v + 1)φ} only sees the fractional part: it lies in [0, 1), and 0 and 1 are the same phase. So the left and right edges of the phase square are the same line, and so are the top and the bottom; glue them and the square becomes a torus. The page is a numerical illustration, not a proof.

  1. The chapter behind it. Chapter 1 · the phase criterion: the deficit c = B is decided by the sum of the two phases (golden_phase_deficit, LEAN ✓).
  2. The two lines are one. Since φ = 1 + 1/φ, the line p₁ + p₂ = φ is p₁ + p₂ ≡ 1/φ (mod 1), so it and the line p₁ + p₂ = 1/φ are two pieces of one closed curve on the torus. The page draws it as one violet tube and checks that the two pieces meet end to end across the glued edges (NUM).
  3. Models and simplifications. The thickness and proportions of the tube and the torus are choices of the picture (MODEL); the beads are the 64 phase pairs with 0 ≤ v₁, v₂ ≤ 7, coloured by the deficit the page computes.
